Hi, I’m Aryan Agrawal. I’m a software engineer in the Developer Productivity group at [Glean](https://www.glean.com/). I work on tooling that helps developers spend less time managing their environments and more time building software.

### Projects I’ve worked on

- **[DevDock](https://github.com/aryan-agrawal-glean/devdock)**: A Rust CLI for managing local and remote development environments in Bazel monorepos. It brings together environment profiles, Tilt orchestration, lifecycle plugins, and an MCP server for AI agents.
- **[DevDock Plugin Library](https://github.com/aryan-agrawal-glean/devdock-plugins-library)**: A collection of DevDock plugins in Rust, Python, Go, and Bash for environment validation, startup timing, logging, and notifications. Each plugin also serves as a starting point for extending your own development workflow.
- **[Tilt MCP](https://github.com/aryan-agrawal-glean/tilt-mcp)**: A Python MCP server that gives AI assistants access to Tilt resource status and service logs, helping them inspect development environments and troubleshoot failing services.

I’m interested in developer infrastructure, reliable development workflows, and making AI tools useful in everyday engineering. Contributions, feedback, and conversations around these projects are always welcome.
